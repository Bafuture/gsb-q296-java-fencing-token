## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们的分布式锁在租约过期后旧持有者可能继续写入，导致两个持有者同时操作同一资源。请从零实现一个带 fencing token 的分布式锁组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ），存储与资源用内存对象模拟。要求：1) 每次成功加锁分配一个严格递增的 token，锁标识与 token 一起返回；2) 被保护的资源在写入时校验 token：小于已见过的最大 token 的写入必须被拒绝，需有测试证明旧持有者无法覆盖新持有者的写入；3) 支持锁超时与自动释放，锁释放后新的持有者获得更大的 token；4) 支持续约：持有者可在到期前延长租约，续约后 token 不变；5) 支持持有者崩溃模拟：崩溃后锁到期被他人获取，旧持有者恢复后的写入必须被资源侧拒绝；6) 支持可重入：同一持有者重复加锁返回同一 token 并增加重入计数；7) 提供统计：加锁次数、被拒绝的过期写入数、续约次数与 token 递增幅度；8) 测试覆盖 token 递增、过期写入拒绝、超时释放、续约、崩溃恢复后拒绝与可重入；`mvn -q verify` 一条命令跑通。
